# 2E: World Setup Questions

`/world-init` asks these **after** the core questions, as one batch, in the output language. Every one is optional; an unanswered item means "standard".

1. **Starting level:** which level do the PCs start at? (standard: 1)
2. **Advancement:** experience points (1,000 per level) or milestones?
3. **Character options:** any limits on ancestries, classes or backgrounds in this world? (e.g. "no spellcasters", "humans only"). Names only; this pack does not describe options, the GM uses their own book.
4. **Hero Points:** standard (1 per session, up to 3), more generous, or off?
5. **Variant rules:** any variant rules from the GM's book (e.g. free archetype, ancestry paragon, automatic bonus progression, proficiency without level)?
6. **Homebrew:** house rules or changes to the standard rules?

Write the answers to `system.md` using `templates/system.md`. Leave "Standard" where the GM changed nothing. Do not invent house rules; if the GM asks for ideas, mark them `(suggestion)` and get a confirmation in the same init conversation. Never fill the world with content from a published setting: ancestries, classes and options are rules, not lore.

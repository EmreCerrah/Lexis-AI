# Fate Core: World Setup Questions

`/world-init` asks these **after** the core questions, as one batch, in the output language. Every one is optional; an unanswered item means "standard Fate Core".

1. **Skills:** the default list of 18, or a list for this world (add, remove or rename skills, e.g. "Lore covers magic", "no Drive")?
2. **Stunts:** any world-specific stunt examples or limits? (e.g. "magic only through stunts")
3. **Special situations:** special rules that will come up often in this world? (e.g. a corruption stress track, night mechanics, a curse counter)
4. **Modifications:** differences from standard, such as the skill cap, number of stress boxes, refresh, number of consequences?
5. **Homebrew:** a fully custom system or house rules? (All of it goes under one heading: Homebrew.)

Write the answers to `system.md` using `templates/system.md`. Leave "Standard" where the GM changed nothing. Do not invent house rules; if the GM asks for ideas, mark them `(suggestion)` and get a confirmation in the same init conversation.

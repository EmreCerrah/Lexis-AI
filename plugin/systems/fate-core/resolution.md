# Fate Core: Resolution

## The roll
The player rolls 4 Fate dice (each −1, 0 or +1) and adds the skill rating. The result is compared with the opposition on the ladder; the difference is the number of **shifts**. You explain; the GM reads the roll.

## Four actions
| Action | Use when |
|---|---|
| Overcome | getting past an obstacle, achieving a goal |
| Create an Advantage | creating or discovering an aspect, or getting free invokes on an existing one |
| Attack | trying to harm someone, physically or mentally |
| Defend | actively stopping someone else's attack or advantage |

The skill follows from *how* the character does it, as the player describes it. When the GM asks "which skill?", give 2-3 skills with the fiction that would justify each, best fit first. If `system.md` defines a custom skill list, use only that list.

## Outcomes
- **Fail:** fail, or succeed at a serious cost.
- **Tie:** succeed at a minor cost, or get a boost instead.
- **Success (1-2 shifts):** succeed.
- **Success with style (3+ shifts):** succeed and get an extra benefit (a boost, a free invoke).

## The ladder
| + | Name |
|---|---|
| +8 | Legendary |
| +7 | Epic |
| +6 | Fantastic |
| +5 | Superb |
| +4 | Great |
| +3 | Good |
| +2 | Fair |
| +1 | Average |
| +0 | Mediocre |
| −1 | Poor |
| −2 | Terrible |

## Teamwork
Each helper with at least Average (+1) in the skill adds +1 to the highest-rated character's roll. Helpers share the cost of a failure.

## Fate points
Refresh 3 by default. Invoke an aspect: spend 1 → +2 or a reroll. Compel: the GM offers 1 → an aspect complicates the character's life; refusing costs 1.

## Answer shape for /help-skills
1. **Action:** Overcome / Create an Advantage / Attack / Defend.
2. **Skills:** 2-3, best fit first, each with the fiction that makes it fit ("forcing the gate is Physique; slipping the latch is Burglary"). Check the table above for what each skill may do. The player's description decides; say so.
3. **Opposition:** a passive difficulty range on the ladder, or the active opponent's likely skill.
4. **Rule hooks:** a matching stunt, an aspect worth invoking, a possible compel, only if one exists in the files or the scene.

```
🎲 <Action: Overcome>
- Skill: Physique — … · Burglary — …
- Suggested difficulty: Fair–Good (+2/+3) — …
- Stunt/aspect: …
```

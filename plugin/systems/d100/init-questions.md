# d100: World Setup Questions

`/world-init` asks these **after** the core questions, as one batch, in the output language. Every one is optional; an unanswered item means "standard".

1. **Power level:** Normal (realistic, horror), Heroic, Epic or Superhuman? (standard: Normal)
2. **Powers:** none, or which kinds exist in this world (magic, psychic abilities, mutations, sorcery, super powers)? Kinds only; the GM uses their own book for the powers themselves.
3. **Skill list:** the standard list, or renamed, added or removed skills for this world (e.g. "Pick Lock instead of Fine Manipulation", "no Firearm")?
4. **Optional rules:** Sanity, Education (EDU), hit locations, fatigue, power points as fate points, total hit points (CON+SIZ)?
5. **Homebrew:** house rules or changes to the standard rules?

Write the answers to `system.md` using `templates/system.md`. Leave "Standard" where the GM changed nothing. Do not invent house rules; if the GM asks for ideas, mark them `(suggestion)` and get a confirmation in the same init conversation. Never fill the world with content from a published setting.

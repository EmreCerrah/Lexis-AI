# FitD: World Setup Questions

`/world-init` asks these **after** the core questions, as one batch, in the output language. Every one is optional; an unanswered item means "standard".

1. **What do the PCs do?** The kind of jobs or missions the crew takes (heists, hunting, smuggling, investigation …). This shapes the playbooks and clocks.
2. **Playbooks:** which character roles exist in this world? Names only; the GM uses their own book or their own playbooks.
3. **Actions:** the standard 12, or renamed or replaced actions for this world (e.g. no Attune if there is nothing supernatural)?
4. **Downtime and crew:** use crew rules (tier, heat, coin, faction clocks), or keep it to characters only?
5. **Homebrew:** house rules or changes to the standard rules?

Write the answers to `system.md` using `templates/system.md`. Leave "Standard" where the GM changed nothing. Do not invent house rules; if the GM asks for ideas, mark them `(suggestion)` and get a confirmation in the same init conversation. Never fill the world with content from the original game's setting.

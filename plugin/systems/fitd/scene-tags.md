# FitD: Scene Tags = Factors and Clocks

This system has no aspects and few fixed modifiers. The scene tag is a **factor**: something true in the fiction that shifts **position** (how dangerous) or **effect** (how much an action can do), or a **clock** that tracks a danger or a goal. It should be usable by the PCs *and* able to hinder them.

## Kinds and their rule effects
| Kind | Typical effect |
|---|---|
| Potency | a weakness, darkness, a distraction, extra time or arcane help: +1 effect for one side (or −1 for the other) |
| Scale | numbers, area, reach: a gang against one person, a whole building to search: raises or lowers effect |
| Quality | tools, resources, defenses: fine gear or a fortified door shifts effect |
| Position factor | cover, a vantage point, being surrounded or cornered: makes the position controlled, risky or desperate |
| Danger clock | "Guards Alerted (4)", "Fire Spreads (6)": ticks 1-3 per complication; when full, the danger happens |
| Progress clock | "Break the Seal (6)": ticks by effect (limited 1, standard 2, great 3); when full, the goal is reached |

## A good scene tag
1. **Concrete and visible:** "Fog Off the River" beats "bad weather". Name it in the world's voice and language.
2. **One clear effect:** position, effect, or a named clock with its size.
3. **Two-sided:** one line on how the PCs can use it, one on how it can work against them.
4. **True in the fiction:** it follows from what happened, obeys `## Immutable Rules`, and reveals no `## 🔒 Hidden Truth`.

## Output block
```
**"<Tag name>"** — <kind: potency / scale / quality / position / danger clock / progress clock>
- Effect: <e.g. +1 effect for Prowl; or clock "Watch Arrives" (4)>
- Use it: <how a PC can exploit it, one line>
- Against them: <how it can hinder the PCs, one line>
```

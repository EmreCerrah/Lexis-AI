# FAE: Aspects

An aspect is a short phrase that is **true in the fiction** and can be **invoked** (for a bonus) and **compelled** (for a complication).

## Kinds
| Kind | Lasts | Example (Turkish world) |
|---|---|---|
| Character aspect (high concept, trouble, others) | permanent until changed | *Işık Tarikatı'nın Son Avcısı*, *Kanı Çağırıyor* |
| Situation / scene aspect | until the scene or situation ends | *Sis Mezar Taşlarını Yutuyor*, *Devrilmiş Variller* |
| Consequence | until healed | *Kırık Kaburga* |
| Boost | one free invoke, then gone | *Bir Anlık Açıklık* |
| Location / group aspect (world files) | permanent | *Kimse Gece Buraya Gelmez* |

## A good aspect
1. **Double-edged:** can help *and* hurt. Test: write one invoke and one compel. If you can't write both, rewrite.
2. **Evocative, short:** 2-6 words, a picture, not a stat. Prefer concrete nouns and verbs over adjectives ("Çürük Tahtalar Gıcırdıyor" > "Tehlikeli Zemin").
3. **True in the fiction:** it must follow from what happened; it must not violate `## Değişmez Kurallar` or reveal a `## 🔒 Gizli Gerçek`.
4. **In the world's voice:** match `world.md` tone and language.

## Free invokes
- Create an Advantage success → 1 free invoke (style → 2). Tie → boost.
- A newly discovered aspect on a hidden thing → note "keşfeden 1 bedava invoke alır" as a reminder only.

## Output block for an aspect
```
**"<Aspect>"** — <tür: sahne / durum / sonuç / boost / kalıcı>
- Invoke: <who can use it, for what, one line>
- Compel: <how it complicates, one line>
```

# FAE: World Setup Questions

`/world-init` asks these **after** the core questions, as one batch. Every one is optional; an unanswered item means "standart FAE".

1. **Approach'lar:** Standart altı approach (Careful, Clever, Flashy, Forceful, Quick, Sneaky) mı, yoksa bu dünyaya özel isimler/listeler mi?
2. **Stunt'lar:** Dünyaya özgü stunt örnekleri ya da stunt kısıtları var mı? (ör. "büyü yalnızca stunt'la")
3. **Özel durumlar:** Bu dünyada sık olacak özel kurallar? (ör. korku/akıl sağlığı stresi, gece mekaniği, lanet sayacı)
4. **Değişiklikler:** Stres kutusu sayısı, refresh, sonuç sayısı gibi standarttan farklar?
5. **Homebrew:** Tamamen özel bir sistem ya da ev kuralları? (Fate Core benzeri skill listesi gibi bir hack dahil — hepsi tek başlık altında: Homebrew)

Write the answers to `system.md` using `templates/system.md`. Leave "Standart" where the GM did not change anything. Do not invent house rules; if the GM asks for ideas, mark them `(öneri)` and ask for confirmation in the same init conversation.

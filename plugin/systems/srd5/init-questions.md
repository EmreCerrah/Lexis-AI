# 5E: World Setup Questions

`/world-init` asks these **after** the core questions, as one batch, in the output language. Every one is optional; an unanswered item means "standard".

1. **Starting level:** which level do the PCs start at? (standard: 1)
2. **Ability scores:** standard array, point cost (27) or 4d6 drop lowest?
3. **Advancement:** experience points or milestones?
4. **Character options:** any limits on classes, species or backgrounds in this world? (e.g. "no spellcasters", "only humans"). Names only; this pack does not describe options that are not in the SRD, the GM uses their own book for those.
5. **Optional rules:** fear and mental stress, lingering injuries, slower healing, encumbrance? (standard: none)
6. **Homebrew:** house rules or changes to the standard rules?

Write the answers to `system.md` using `templates/system.md`. Leave "Standard" where the GM changed nothing. Do not invent house rules; if the GM asks for ideas, mark them `(suggestion)` and get a confirmation in the same init conversation. Never fill the world with content from a published setting: species, classes and options are rules, not lore.

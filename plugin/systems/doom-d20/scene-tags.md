# Doom d20: Scene Tags = DR Shifts and Hazards

This system has no aspects and almost no modifiers. The scene tag is a **DR shift**: something true in the fiction that makes certain tests easier or harder (usually by 2, sometimes 4), or a **hazard** that forces a test. It should be usable by the PCs *and* able to hinder them.

## Kinds and their rule effects
| Kind | Typical effect |
|---|---|
| Terrain | mud, ice, rubble, a narrow ledge: Agility tests DR +2 (or +4); a high position: attacks from it DR −2 |
| Light | darkness, smoke, fog: Presence tests to see or shoot DR +2 or more; sneaking DR −2 |
| Weather | rain, freezing cold, storm: Toughness tests to endure; ranged attacks DR +2 |
| Advantage | a prepared trap, a distraction, a good tool: one kind of test DR −2 |
| Hazard | fire, poison, a fall, a collapse: a test (usually Agility or Toughness) or take damage (d4 to d10 and up) |

## A good scene tag
1. **Concrete and grim:** "Blood-Slick Stairs" beats "slippery floor". Name it in the world's voice and language.
2. **One clear effect:** a DR shift for a named kind of test, or a hazard with its test and damage.
3. **Two-sided:** one line on how the PCs can use it, one on how it can work against them.
4. **True in the fiction:** it follows from what happened, obeys `## Immutable Rules`, and reveals no `## 🔒 Hidden Truth`.

## Output block
```
**"<Tag name>"** — <kind: terrain / light / weather / advantage / hazard>
- Effect: <e.g. Agility tests DR +2 here; or Toughness DR 12 or take d6>
- Use it: <how a PC can exploit it, one line>
- Against them: <how it can hinder the PCs, one line>
```

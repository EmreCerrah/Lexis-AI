# /help-skills

A rules question at the table, answered in the **world's system** and its own terms. This skill records nothing and writes nothing.

## Read first
`../../AGENTS.md`; the world's `world.md` (`system:` field) and `system.md` (Homebrew overrides the standard); `../../systems/<system>/pack.md` (glossary) and `resolution.md` (rules and **the answer shape**); the acting PC's file if named (traits, special abilities, scene tags); the scene context from the open log if relevant.
If there is no world folder: use the system the GM names; if none is named, ask in one line which installed system (`../../systems/*/pack.md`) to use.

## Answer
Follow `## Answer shape for /help-skills` in the pack's `resolution.md`: the kind of check, 2-3 fitting traits each with the fiction that makes it fit (best fit first; the player's description decides, say so), a suggested difficulty, and rule hooks from the PC's file or the scene, only if they exist. Add a Homebrew note if `system.md` changes anything. Use the pack's terms (glossary), never another system's.

## Output (table mode, in the output language, at most 5 bullets)
The output block in the pack's `resolution.md`.

## Never
Decide which trait the player must use, set the final difficulty, roll, or record anything.

# /help-skills

The GM says "skill"; Fate Accelerated uses **approaches**. Answer in approach terms. This skill records nothing and writes nothing.

## Read first
`../../AGENTS.md`; `../../systems/<system>/approaches.md`; the world's `system.md` (Homebrew overrides the standard, e.g. a custom skill list); the acting PC's file if named (approach ratings, stunts, aspects); the scene context from the open log if relevant.
If there is no world folder, answer with standard FAE and say so in one short line.

## Answer shape
1. **Action:** which of the four actions (Overcome / Create an Advantage / Attack / Defend).
2. **Approaches:** 2-3, best fit first, each with the fiction that would make it fit ("vaulting the wall fast is Quick; testing each handhold is Careful"). The player's description decides; say so.
3. **Opposition:** a passive difficulty range or the active opponent's likely approach.
4. **Useful rule hooks:** a matching stunt, an aspect worth invoking, a possible compel, but only if one exists in the files or the scene.
5. A Homebrew note if `system.md` changes anything.

## Output (table mode, in the output language, at most 5 bullets)
```
🎲 <Action: Overcome>
- Approach: Quick — … · Careful — …
- Suggested difficulty: Fair–Good (+2/+3) — …
- Stunt/aspect: …
```

## Never
Decide which approach the player must use, set the final difficulty, roll, or record anything.

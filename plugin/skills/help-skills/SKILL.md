# /help-skills

The GM says "skill"; Fate Accelerated uses **approaches**. Answer in approach language. Records nothing, writes nothing.

## Read first
`../../AGENTS.md`; `../../systems/<sistem>/approaches.md`; `system.md` of the world (Homebrew overrides standard — e.g. a custom skill list); the acting PC's file if named (approach ratings, stunts, aspects); the scene context from the open log if relevant.
If there is no world folder, answer with standard FAE and say so in one short line.

## Answer shape
1. **Action:** which of the four actions (Overcome / Create an Advantage / Attack / Defend), with Turkish gloss.
2. **Approaches:** 2-3, best fit first, each with the fiction that would make it fit ("Duvara hızla atlarsa Quick; tutamakları tek tek yoklarsa Careful"). The player's description decides; say so.
3. **Opposition:** passive difficulty range or the active opponent's likely approach.
4. **Useful hooks into rules:** a matching stunt, an aspect worth invoking, a possible compel. Only if one exists in the files or the scene.
5. Homebrew note if `system.md` changes anything.

## Output (Turkish, table mode, max 5 bullets)
```
🎲 <Aksiyon: Overcome (Engeli aş)>
- Approach: Quick (Hızlı) — … · Careful (Dikkatli) — …
- Zorluk önerisi: Makul–İyi (+2/+3) — …
- Stunt/aspect: …
```

## Never
Decide which approach the player must use, set the final difficulty, roll, or record anything.

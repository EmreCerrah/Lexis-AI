# Lens Index

Lenses are analysis perspectives. They are **not skills**: the GM never calls them. `/event` and `/ripples` read this index, pick lenses, then open only the lens files they picked.

## How to pick
1. Read the event: what changed, where, who was involved, which hooks it touches.
2. Score each lens below by its triggers and pick the highest.
   - `/event` (table): **at most 2**; 3 only if the event clearly touches three areas.
   - `/ripples`: 2-3 in table mode; every lens that scores in prep mode.
3. If no lens fits well, use `society-rumor`: every event leaves a rumor trail.
4. Name the picked lenses in the output header line, for example `Lens: power-politics, faith-supernatural`.

## Available lenses
| File | Lens | Pick when the event touches… |

| `power-politics.md` | Power and Politics | rulers, factions, law, order, guards, debts of loyalty, who gains or loses authority |

## Lens file contract
Every lens file has the same sections: **Focus**, **Triggers**, **Questions**, **Spread channels**, **Typical ripples**, **Pitfalls**. A new lens must follow this contract and be added to the table above.
